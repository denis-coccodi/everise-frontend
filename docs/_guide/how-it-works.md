# How it works

The site gathers what the community already shares about the game, and shows it in one place, in the game's look. Nothing on the site runs inside the game.

## Where the information comes from

| On the site                                         | Comes from                                                         | How fresh                                  |
| --------------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------ |
| Posts, comments, profiles                           | Members, on this site                                              | Instant; new posts appear live             |
| Weekly (Fashion Report, Island Sanctuary) and Hunts | Channels the free company's Discord follows                        | Checked every 2 minutes                    |
| Party Finder                                        | Players who run a community Party Finder plugin, via xivpf.com     | Refreshed every 30 seconds while you watch |
| Events                                              | Partake, the community's event calendar                            | Every few minutes                          |
| Venues                                              | FFXIV Venues, the community's venue index                          | Every few minutes                          |
| Market History                                      | Universalis, from players' market board uploads                    | Read when you ask, kept up to date         |
| Duties, roulettes, jobs, game images                | The game's own data, through XIVAPI                                | Refreshed after each game patch            |
| Resets                                              | The game's reset times (daily 15:00 UTC, weekly Tuesday 08:00 UTC) | Shown in your time zone                    |
| The Waking Sands' characters                        | An AI, playing each character from a description                   | As they're talking                         |
| Fight Planner                                       | FFLogs reports                                                     | Read when you open a report                |

The site is a fan project: FINAL FANTASY XIV © SQUARE ENIX CO., LTD. Game images are used under Square Enix's fan site materials licence.

## Discord

The site and the free company's Discord work together:

- **From Discord to the site:** the Weekly and Hunts tabs show what the Discord receives from the channels it follows.
- **From the site to Discord:** posts, parties, events and venues go to the Discord only when a member chooses to share them.
- **On the home page:** links to join the Discord.

## How changes reach the site

1. **Staging first:** every change is tried on a separate copy of the site, the [staging site](/guide/testers-and-admins/), where invited testers can see it.
2. **Then everise.dev:** when it's ready, it's released here. Bigger features are switched on only once they're finished.
{: .steps}

## Light and dark

The site looks like FINAL FANTASY XIV, in dark mode by default or a "Final Fantasy white" light mode. It's built to be usable by everyone: with the keyboard, with screen readers, zoomed in, and on a phone.
