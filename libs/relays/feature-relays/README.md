# relays

The home page's Weekly and Hunts tabs (a widget): what the Everise Discord relays from the channels it follows, shown as Discord shows it. `cdt-weekly`: the next resets, this week's Fashion Report with the days it's for (or when judging opens again), and the Island Sanctuary workshop recommendations. `cdt-hunts`: the hunt trains to come, running and last started, a window per data centre (Light first). `cdt-discord-message` shows one relayed message: its text (`cdt-discord-text`, Discord's Markdown read by `discord-markdown.ts` into nodes the template renders, never HTML: custom emoji from Discord's CDN, times in the reader's time zone), its cards (`cdt-discord-embed`) and its pictures in the media grid (GIFs pause). Pictures Discord's links would lose are served by the backend (`/api/relays/images/:file`, `relay-pictures.ts`). Data comes from `@everise/relays/data-access`.
