# events-feature-event-card

`cdt-event-card`: one community event from Partake as a card, shared by the pages that show events (a widget library, so no page imports another).

- On the Events page: its banner, title linking to its page here, when it is in the visitor's time, where, who hosts it, a "Mature" label for MATURE events, the start of its description, a few tags, and links to its team's Discord and its Partake page.
- `[compact]="true"`, on a venue's page: only the banner, title, when, rating and links, as where it is and who hosts it are the venue.
