# party-finder-data-access

The Party Finder page's data: `PartyFinderService` (`GET /api/party-finder`, a data centre's listings as the backend last read them from xivpf.com) and `PartyFinderStore`, the page's state: the chosen data centre's listings, refreshed every 30 seconds while the page is in view, the filters (world, category, open role, search, listings without a duty, beginners welcome), the order and the page (20 listings a page). `listing-filters.ts` holds the filtering and the category names; `listing-sort.ts` the orders, the game's first (by Party Finder tab, high-end duty by kind, then the highest level duty first, the duty's sort key (newest first) among duties of one level, one duty's listings by time left). `party-finder-query.ts` keeps all of it in the page's query string, by id (`?dc=light&world=odin&sort=ending-soon`...): the store reads it, writes every change back and follows it on Back, Forward and links. Without a data centre the page starts on Light from Odin; picking one shows all its worlds.
