# party-finder-feature-party-finder

The Party Finder page (`/party-finder`, open to everyone): the listings up on any data centre (Light first), as xivpf.com collects them from players' Remote Party Finder plugin, refreshed every 30 seconds while the page is in view. `cdt-pf-filters` picks the data centre (by region), the world the member plays from (the whole data centre plus that world's own Hunt and FATE parties), a category, an open slot for a role, words to find and the order (the game's by default), with switches for listings without a duty and beginners; `cdt-pf-listing` shows one listing (its duty type's icon before the name). The page shows 20 listings a page under `cdt-pager`, and keeps the page and the scroll position through refreshes. The state is `PartyFinderStore` in `@everise/party-finder/data-access`.
