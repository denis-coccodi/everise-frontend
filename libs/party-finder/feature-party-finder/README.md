# party-finder-feature-party-finder

The Party Finder page (`/party-finder`, open to everyone): the listings up on Light or Chaos, as xivpf.com collects them from players' Remote Party Finder plugin, refreshed every 30 seconds while the page is in view. `cdt-pf-filters` picks the data centre, the world the member plays from (the whole data centre plus that world's own Hunt and FATE parties), a category, an open slot for a role and words to find, with switches for listings without a duty and beginners; `cdt-pf-listing` shows one listing. The state is `PartyFinderStore` in `@everise/party-finder/data-access`.
