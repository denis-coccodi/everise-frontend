# party-finder-feature-pf-listing

A Party Finder listing's card (`<cdt-pf-listing>`), with its party's slots (`<cdt-pf-party>`) and the times it shows (`listing-time.ts`). A widget: the Party Finder page lays its listings out with it, and the feeds and a post's page show a shared listing with it.

Run `nx test party-finder-feature-pf-listing` to run its tests.
